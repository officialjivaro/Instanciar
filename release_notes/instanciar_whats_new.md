# What’s New in Instanciar

Instanciar is becoming a clearer, more user-focused browser workspace for managing multiple Chrome-based instances. Recent updates focus on a better dashboard, stronger setup visibility, more consistent region/profile controls, and a live What’s New panel that can be updated from GitHub without requiring users to redownload the app.

[Download Latest Instanciar](https://www.jivaro.net/content/programs/instanciar)

---

## 2026-06-04 — Instanciar v0.14

### Live What’s New panel

- Replaced the old startup update popup with a live What’s New panel.
- What’s New content now loads directly from GitHub.
- Added **Help → What’s New** so users can reopen the panel anytime.
- Added a **Download Latest** action that points to the official Instanciar page.
- Removed bundled/local release notes from the app.
- If GitHub cannot be reached, Instanciar now shows a clear message that the live notes could not be loaded.

### Why it matters

Release notes can now be updated live without rebuilding or redistributing the app. Users get current information when the app opens, and the app no longer needs to store release notes locally.

---

## 2026-06-04 — Instanciar v0.13

### Dashboard and workflow polish

- Reworked the dashboard into a darker, more user-first layout.
- Added dashboard search/filter so instances and groups are easier to find.
- Added setup-issue filtering so profiles that need attention are easier to spot.
- Added a Donate button linking to the official Jivaro donation page.
- Improved dashboard text wrapping and resizing behavior around the tree and details panel.
- Removed the old Antidetection checkbox and the active save/launch code tied to it.

### Why it matters

This update makes day-to-day instance management easier to understand. The dashboard now surfaces status, warnings, and common actions more clearly, so users can manage browser profiles with less guesswork.

---

## 2026-06-03 — Instanciar v0.12

### Browser profile and region consistency

- Added Region Profiles that connect area, timezone, and language settings.
- Added Browser Modes such as **Normal Browser** and **Privacy Browser**.
- Added setup health warnings for profiles with mismatched or risky settings.
- Updated the Instance Manager into clearer sections:
  - Basic
  - Proxy
  - Region
  - Browser Profile
  - Health Check
- Added region and browser-mode details to the dashboard inspector.

### Why it matters

Profiles are easier to configure consistently. If proxy, region, timezone, language, or WebRTC settings do not line up, Instanciar can now warn you before launch.
